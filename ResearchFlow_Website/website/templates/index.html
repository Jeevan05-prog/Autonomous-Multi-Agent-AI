PROJECT OVERVIEW

About ResearchFlow AI

An autonomous multi-agent workflow orchestration platform.

R

ResearchFlow AI

From a research question to a structured, evidence-aware report — powered by six cooperating agents.

Orchestration

LangGraph connects the agents, manages their shared state and supports conditional routing when the Critic requests more research.

Language model

Gemini supports AI-powered planning and summarization. Fallback behaviour in the existing project can keep parts of the workflow running if the model is unavailable.

Research & data

DuckDuckGo search gathers web results. Pandas and Matplotlib process uploaded CSV files and generate visualizations.

Two operating modes

Web Research Only works without a CSV. Research + Data Analysis combines external research with a user-provided CSV dataset.

ResearchFlow AI is a research assistant. Always verify important claims and figures against the original sources. Web-only numerical evidence is extracted from source snippets and is not a substitute for a validated dataset.
